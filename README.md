## ☁️ Deploy Free on Vercel

1. Push this repository to GitHub (`Eshaan1234/Portfolio`).
2. Go to [vercel.com/new](https://vercel.com/new), import `Eshaan1234/Portfolio`, and click **Deploy**.
3. Vercel gives you a free `https://<your-project>.vercel.app` domain with automatic HTTPS!

## 🌐 Connecting a Custom `.in` Domain Later (Optional, Paid)

`.in` domains are managed by NIXI and require an annual fee (~₹400–₹799/year via registrars like Hostinger India, Spaceship, Porkbun, Namecheap, or GoDaddy India). Whenever you buy one:

1. Open your project on **Vercel → Settings → Domains**.
2. Type your `.in` domain (e.g., `eshaangupta.in`) and click **Add**.
3. In your domain registrar's **DNS Management** panel, add the two records Vercel shows:
   - **Type `A`** | Host: `@` | Value: `76.76.21.21`
   - **Type `CNAME`** | Host: `www` | Value: `cname.vercel-dns.com`
4. Wait 5–30 minutes for DNS propagation — Vercel provisions your SSL certificate automatically for free!
